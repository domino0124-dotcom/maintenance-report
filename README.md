## 🗂️ 後端在哪裡（Google Apps Script 主專案）

| GAS 檔案 | 對應的網頁 |
|---|---|
| `集點系統.gs` | points.html、points-admin.html |
| `帳務系統.gs` | ledger.html（需要和集點系統.gs 放同一個專案） |
| `預約系統.gs` | booking.html、booking-admin.html |
| `程式碼.gs` | LINE 機器人主程式（doPost） |

另一個 GAS 專案 **韋德圖文選單**：韋德機車精品帳號的圖文選單（改完執行 `setupRichMenus`）。

資料都存在同一個 Google 試算表，分頁：店面收支、廠商帳款、蝦皮營收、集點會員、集點紀錄…

## 🔄 更新的固定流程

1. **網頁（.html）**：GitHub → Add file → Upload files → 同名覆蓋 → 等 1～2 分鐘
2. **GAS（.gs）**：貼上覆蓋 → 存檔 → 管理部署作業 → 編輯 → **新版本** → 部署（不要建新部署）
3. 新增網頁：照這個表的格式，在對應分類加一行
